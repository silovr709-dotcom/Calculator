# Фрезеровки фасадов: каталог 2026 вместо технички 2023

Источник: **«Каталог Фрезеровок ВИСМА 2026_compressed (1).pdf»** (76 страниц, загружен
в репозиторий 29.09.2026). Он заменил список фрезеровок из «Техничка фасады октябрь 2023».

## Почему каталог 2026 главнее технички 2023

Каталог сходится с действующим прайсом, а техничка — нет:

| | Техничка 2023 | Каталог 2026 | Прайс «ВИСМА 2026 КХМ» |
|---|---|---|---|
| Категорий фрезеровок | 5 | **4** | **4** (`1–4 категория (плёнки)`, `фрезеровка 1–4 кат`) |
| Позиций | 50 | **60** | — |

Именно категория фрезеровки задаёт цену квадратного метра фасада, поэтому расхождение
в количестве категорий — не косметика: по техничке 2023 «Белладжо» шла 5-й категорией,
которой в прайсе 2026 просто нет.

## Как данные попали в приложение

В PDF **нет текстового слоя**: при вёрстке весь текст переведён в кривые, автоматический
парсер вернёт пустые страницы. Поэтому:

1. `tools/millings-visma-2026.tsv` — расшифровка каталога, строка = страница каталога.
   В каждой строке указан номер страницы PDF, по которому значение перепроверяется глазами.
2. `tools/extract_millings.py` — читает расшифровку, проверяет её на непротиворечивость
   (дубли имён и страниц, категории 1–4, полнота 60 позиций) и отдаёт нормализованный список.
3. `tools/extract_factory_dicts.py` — кладёт результат группой `millings`
   в `app/public/data/factory-dicts-visma.json` рядом с разбивками цветов.
4. `tools/render_milling_images.py` — рендерит превью фасадов из страниц каталога
   в `app/public/img/millings/*.jpg` (60 файлов, ~650 КБ суммарно: сам PDF в 24 МБ
   в браузер тянуть нельзя).

Обновление после нового каталога:

```bash
python3 -m pip install openpyxl pymupdf pillow
# 1. поправить tools/millings-visma-2026.tsv по страницам нового PDF
python3 tools/extract_millings.py          # отчёт и проверки
python3 tools/extract_factory_dicts.py     # пересобрать справочники
python3 tools/render_milling_images.py     # пересобрать превью
cd app && npm test
```

## Что это даёт в приложении

- **База знаний → «🪚 Фрезеровки»**: 60 карточек с картинкой, категорией, фаской, шириной
  рамки, толщиной МДФ, допустимыми размерами (глухой / РК / РБК / ящик) и **ценой м²
  из прайса** — отдельно ПВХ (16/19/22 мм) и эмаль (матовая / глянец / металлик).
- **Бланк на фабрику**, поле «Тип фрезеровки/фаска»: подсказки из каталога и проверки —
  неизвестное название, «только эмаль» при ПВХ, плёнка с пометкой «только Мыло»,
  примечания страницы («переход рисунка не совпадает», «радиус не изготавливается»).

## Замечания к самому каталогу

- В подвале страницы 49 файла напечатан номер **50**, хотя по порядку это 48 — номер 50
  встречается дважды (Дублин и Мадрид). Поэтому источником ссылки в данных служит
  **номер страницы PDF**, а не напечатанный номер. Скрипт выводит это расхождение
  в отчёт, и оно же видно в приложении в блоке «Замечания к самому каталогу».
- Страницы 61–76 — декоры (кресты рамок, решётка, улыбка, интегрированные ручки J/V/H,
  пилястры №1/№2), багет, радиусные фасады и листы для заметок. Это не фрезеровки фасадов,
  в справочник `millings` они не входят.
