## Общее

- Горячие клавиши: на русской раскладке не работали (сравнение по символу) — исправлено, сравнение по коду клавиши.
- Фокус после выбора в списке блокировал клавиши — исправлено (клик по полотну снимает фокус, Esc выходит из поля).
- Размер текста: минимум 12 → 6 для текстовых объектов (петли 8–28).
- Двойной клик по тексту открывает «Свойства» и ставит курсор в поле текста.
- Справка по клавишам: `?` или F1, кнопка «Клавиши ?».
- Подсказка в строке состояния меняется по инструменту.

## Что проверить на устройстве

1. Выноска: «Рамка» выкл. — прямоугольник пропадает, линии к цели остаются.
2. Фасад: при минимальном размере (8) номер читается, кружок не пропадает на полотне.
3. Калибровка: отметить два конца известного размера, введённая длина сохраняется, новый размер получает значение в мм.
4. Русская раскладка: V, R, M, Ctrl+Z, Ctrl+C работают.
